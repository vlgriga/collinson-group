This is more open-ended than a real ticket would be, and that's deliberate. In day-to-day work the shape of a task gets worked out together as a team, and you'd help define it. We've left this one loose so we can see that thinking.

This is a backend exercise.

Description:
Build a backend service that takes a city or town and ranks how good the next 7 days will be for each of these activities:
- Skiing
- Surfing
- Outdoor sightseeing
- Indoor sightseeing

Open-Meteo provides the weather data. Persist it rather than calling the API on every request. How you model, store, and refresh it is part of the problem.

Stack:
Node.js, TypeScript and GraphQL. Storage is your call.
