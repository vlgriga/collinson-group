# Feature designs

> Related: [Requirements](../prd.md) · [Architecture](../architecture/) · [Workflow](../workflow-lifecycle.md#planning)

One design doc per feature: how it is built within the [architecture](../architecture/), the
alternatives, how it is tested and its risks. Each is written in planning, under the feature's
"Design" issue, from the template in the
[`/plan-feature` skill](../../.claude/skills/plan-feature/SKILL.md#3-design), and is a record of
the feature once it is built.
